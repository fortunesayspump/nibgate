- **Wallet-possession rule (access-control session, both apps):** a bare `?wallet=`/`walletAddress` is a client **claim**, never an identity — it may pick a price tier / invite-only eligibility but never grants content on its own. Granting paths (free invite-only reads, lifetime re-issue, whitelist free-tier where `whitelistPrice=0`, media) require **possession**: a valid bound `unlockProof` for that wallet OR a SIWE session (`auth_session` hub / `sb_auth_session` subblogs) whose wallet matches the claim. Paid invite-only shares also require the **paying wallet to equal the possessed wallet** (`403` otherwise), and **all** invite-only shares `403` a non-whitelisted wallet **before any charge** (no pay-before-deny, never a 402).
- **Proof format (hub `utils.js`):** `{wallet}.{iat}.{exp}.{mac}`, `mac = HMAC-SHA256("nibshare:{shareId}:{wallet}:{iat}:{exp}")` keyed by `NIBGATE_GATEWAY_SECRET`/`NIBGATE_PROOF_SECRET`, 12h `iat`/`exp` window (mirrors SDK `DEFAULT_UNLOCK_SECONDS`). Legacy `{wallet}.{mac}` (no claims) still verifies. Proof expiry is HARMLESS — entitlements rule before any proof check, so an expired proof is re-minted on the next legit visit.
- **Atomic receipt idempotency:** x402 has no payment id → the nonce is the x402 `txHash`; DB enforces UNIQUE `(paymentNonce, shareId)`. `grantUnlock` does find-or-create; a `P2002` race re-reads the stored receipt and returns `{receipt, replay: true}` — one grant per payment, no double unlockCount/view bump. Free grants use `free-<uuid>` nonces, `source` field on entitlement: `'paid'` (lifetime) vs `'free'` (re-granted per visit); `sourceMax` never downgrades paid→free.
- **`updateAccessPolicy` cutoff (gap #11):** `cuttingOff = (publicAccess===false && flippingInviteOnly) || (alreadyInviteOnly && whitelistChanged)` — fires on the flip AND on whitelist edits of shares already invite-only (removing a wallet cuts that payer off). Uses SDK `paidCutoffWallets({policy,entitlements,receipts})`, revokes those entitlements, marks latest paid receipt `refundedAt`, returns `cutOffWallets`. Same fix in subblogs `access.service.js` and `blog.service.js` `update()`.
- **Draft/revoked/expired reachability:** hub `assertReachable` (draft→404, revoked→410, expired→419) applied on access/media/meta/manifest/quote; subblogs `/access`, `serveAccess`, `mediaAccessResult`, and document/media routes 404 non-published posts and draft-aware gates.
- **Cache hygiene (x402 Attack III, added after online audit):** gated bodies (hub `accessShare`/`unlockShare`, subblogs `serveAccess`) set `Cache-Control: private, no-store` so a shared `nginx proxy_cache`/CDN can never serve a paid/invite-only 200 to a non-payer; media stays `private, max-age=300`. Origin `@circle-fin/x402-batching` middleware `require()` = facilitator-bound settlement (matches the paper's recommended model; no raw optimistic chain reads).
