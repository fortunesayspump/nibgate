# How JEV decides

JEV is TypeSafe's structured decision model. Dr. Nib separates proposing an action from judging it: the research model proposes, JEV returns a structured choice or score, and runtime policy decides whether the action may execute. A JEV decision cannot authorize an unsupported tool, exceed a cap or override the owner's scope.

The ordinary worker calls JEV through the Hub. The private worker calls the pinned OpenRouter/TypeSafe Decisions route directly, with disclosed provider visibility and required ZDR. The two transports and their audit records differ; see [private model routing](/dr-nib/confidential/models-tools).

## Decision shapes

| Shape | Meaning | Ordinary Hub endpoint | Response |
| --- | --- | --- | --- |
| Choice | Choose among explicit alternatives | `POST /hub/jev/decide` | Choice, probabilities, confidence, model and usage |
| Noul | Score whether a statement holds | `POST /hub/jev/classify` | Probability from 0 to 1, model and usage |
| Score | Position on an ordered scale | `POST /hub/jev/score` | Weighted score, probabilities and confidence |
| Batch | Ask independent questions together | `POST /hub/jev/batch` | Answers keyed by question ID, with shared model/usage metadata |

Use the canonical Hub host, `https://api.nibgate.xyz`, with the paths above. The ordinary worker's internal client uses compatible legacy route aliases. Private judgment context must not be sent through the ordinary Hub transport.

A probability is a model estimate, not a correctness certificate. Confidence describes concentration among alternatives; a confident answer can still be wrong. Source evidence, deterministic checks, budget gates and human review remain separate safeguards. Recorded model/version and usage identify the actual response rather than assuming an alias always serves the same version.

## Ordinary transport

The client clamps state to 4,000 characters, instructions to 500 and candidate context to 2,000. Ordered levels are capped at six with 200 characters per label. Batch instructions and choice-option descriptions are each bounded to 500 characters. The default request timeout is 60 seconds, configurable through `JEV_TIMEOUT_MS`.

```json
{
  "state": "The user has supplied the topic, audience and scope.",
  "instructions": "Choose whether another answer would materially change the plan.",
  "candidates": [
    {"id": "proceed", "context": "Plan from the supplied brief."},
    {"id": "ask_more", "context": "Ask a useful missing clarification."}
  ],
  "questionId": "intake-stop"
}
```

Choices return a concrete pick plus per-option probabilities. Noul returns a probability. Batch accepts an array of question records containing `id`, `type`, `instructions` and choice `options` where applicable. A question ID identifies the record; instructions and option descriptions carry the actual judgment criteria.

## Decision points and failure behavior

| Point | Behavior | When judgment is unavailable |
| --- | --- | --- |
| Ordinary intake | `proceed`, `ask_more` or `reframe`; question threshold checked between batches | Labeled deterministic-bank fallback |
| Ordinary free tool read | Schema, policy and budget checks create a deterministic approval row by default | No model round trip; `DRNIB_JUDGE_ALL=1` disables this fast path |
| Money-moving tool | JEV chooses `execute`, `skip` or `answer` | Execution stops; no silent approval |
| Ordinary source trust/grade batch | Selected sources get trust nouls and quality-tier choices | Trust failure parks the run; an absent valid grade leaves it ungraded |
| Ordinary standalone grade | Probability-weighted ordered score | Returns ungraded without parking |
| Ordinary report verification | Sampled claims are checked against collected passages | Pass is marked unverified rather than inventing support |
| Research round control | Decide whether more evidence is worth another round | Parks rather than guessing |
| Private workflow judgment | Fixed hosted JEV route with its explicit request/response validation and encrypted activity | Fails closed; completed operations remain recoverable under the private journal |

Ordinary choice/noul helpers park with `pauseReason: 'jev'`. The standalone tool loop records `judge-unreachable`; it does not itself turn every use of the loop into a paused research run. The surrounding workflow handles that result. Intake fallback and ungraded sources are explicit exceptions to the blanket claim that every JEV outage behaves identically.

## Spending confidence and binding

In the ordinary tool loop, money-moving `execute` decisions below confidence 0.6 become skips. Allowed free reads use deterministic policy by default. When all-tool judging is enabled, a free read does not use the money confidence threshold.

The approval binds a canonical fingerprint of the proposed tool and input. Immediately before execution, the runtime rejects a changed payload rather than applying an earlier decision to different arguments. The executor then applies its own availability, source eligibility, URL, price, balance and network checks.

## What is recorded

Ordinary decision helpers persist `ResearchDecision` records and publish activity events with sequence, type, stage, prompt, question fields, output, confidence and serving-model/usage metadata where available. The retained question fields depend on the helper: not every row stores the full submitted state or exact provider prompt. Source batches include their bounded state; ordinary choice/noul helpers retain the instruction/option fields they record. A decision row is not a complete network capture.

Private decisions and activity are stored inside encrypted project history, while restricted usage metadata supports accounting. Neither path promises to expose hidden model chain of thought. The visible record is the question, decision, probabilities, stated action summaries and observed results.

## Verification is a separate layer

Ordinary report verification extracts a bounded sample across report chunks and asks JEV about the best collected passage for each claim. The default support threshold is 0.6 (`VERIFY_SUPPORT_THRESHOLD`); outcomes are supported or unknown. The private path instead validates exact source quotes or numbered passages and can run bounded report repair. Both are sampled evidence checks, not certification of every sentence.

The ordinary Hub can select its configured model alias and records the concrete returned model. Private routing pins its approved TypeSafe model/provider policy. Neither route sends image/Box requests through the Dr. Nib judgment client; uploaded image text is extracted by the source-processing layer.
