# Tool reference

> **Processing scope:** this reference describes the ordinary research/API contract. Browser-encrypted state, verified worker key delivery and hosted-model boundaries are documented in [Privacy & confidential processing](/dr-nib/confidential). Ordinary API/MCP access is not a private-project decryption interface.

Every instrument the agent can reach for, with exactly what each one needs. Required inputs are enforced *before* anything costs a judgement call or execution — a missing field avoids a judge/tool invocation and returns actionable feedback. Generating the rejected proposal can still consume model tokens.

Per-call tip/unlock/x402 ceilings default to $1/$2/$2 and are configurable through `DRNIB_SPEND_MAX_TIP`, `DRNIB_SPEND_MAX_UNLOCK` and `DRNIB_SPEND_MAX_X402`. Availability depends on deployment configuration.

**Reference:** `dr-nib/backend/src/tools/executor.js`, `dr-nib/backend/src/agent/loop.js` (`REQUIRED_INPUTS`), `dr-nib/backend/src/spend/`.

Owner-authenticated source tools on ordinary Dr. Nib MCP 0.2.7: `attach_source`, `list_supplied_sources`, `read_supplied_source`. These share file limits, image OCR and storage behavior with the browser. MCP's trusted service key grants authority over any named owner wallet; see [API contracts](/dr-nib/protocol) before integrating. A fallback plan made while the research model is unavailable cannot be funded; reconfigure the run to retry planning. See also [supplied sources](/dr-nib/retrieval).

## Research tools (free or metered, policy-approved)

| Tool | Input | Cost | Returns as evidence |
|---|---|---|---|
| `web_search` | `query` (full question or keywords) | metered | ranked results |
| `web_fetch` | `urls` (array of public URLs) | metered | extracted documents; paywalls/bot-checks reported, never worked around |
| `search_sources` | `query` | $0 | ranked passages from evidence already collected for the run |
| `http_request` | `url` + optional method/headers/body | $0 | status + headers + body; HTTP 4xx/5xx (except 402) count as failures, staying retryable |
| `run_code` | `command` (one shell line) or `code` with optional `language` | runtime estimate | stdout in an isolated ephemeral VM — RPC reads, dataset crunching, parsing. Keys never enter the sandbox |

Observations are formatted before anything reads them: short hex values gain decimal annotations (`0x4a817c800 (20000000000)`), KB-sized blobs collapse to placeholders, and injection patterns are quarantined as data-never-instructions with the banner kept in the audit trail.

The ordinary sandbox requires Railway sandbox configuration, permits outbound public networking, and receives no worker/API/wallet secrets. Its returned cost uses elapsed time and rate assumptions rather than a provider billing receipt. Private code/terminal execution is a separate bounded local/gVisor path with approved cached egress.

## Onchain spending tools (JEV-judged)

| Tool | Input | Default ceiling | Settles |
|---|---|---|---|
| `tip_creator` | `contentUrl` + `amount` (USD) + optional `recipient` + `title` | $1 | hub tip rail: challenge → transfer → verify, receipt + tx hash. Unresolved creators fall back to the domain holding box (claimable later). API-endpoint URLs are rejected — tip creator pages, not the APIs that listed them. |
| `unlock_content` | `url` of the gated page | $2 | same x402 pay, shaped as evidence (body joins the scorable set) |
| `pay_x402` | `url` + optional `body` (the endpoint's POST input) | $2 | an x402-gated API offering USDC on this deployment's Arc network. Price is read off the 402 challenge — never pass an amount; another-chain offer or unreadable price is refused before funding |
| `rate_content` | `contentId` (or page `url` to resolve via the hub index) + `stars` (1–5) + `unlockRef` (the `unlock_content` payment tx — required, ratings without an unlock receipt do not count) | gas only (run dust gate $0.05) | prepare → agent-wallet `rateContent` → hub index; chain must match the spend chain |

On explicit spend tasks the standalone loop funnels once free evidence is banked: first a nudge naming the spend tool, then turns restricted to spend-or-finish so it converges instead of polishing forever. Research runs that ask whether a paid source is worthwhile keep that choice open; their named URLs are previewed for free before any judged purchase.

<Callout type="info">
Direct transfers route through the [spending mandate](/dr-nib/gates) when configured, with no silent EOA fallback. Gateway x402 flows stay EOA-bound (contracts can't sign authorizations) under the caps above.
</Callout>

## What the agent sells (for external agents)

Dr. Nib meters its own retrieval to any agent with USDC — payment is the authentication, zero accounts:

| Endpoint | Default price | Does |
|---|---|---|
| `POST /v1/x402/search` | $0.01 | search over configured providers |
| `POST /v1/x402/read` | $0.01 | fetch + extract one page (PDFs and Office docs included) |

Both return a standard x402 challenge (402 + `payment-required`); Circle Gateway settles and the content comes back. Unconfigured deployments answer 501. Search/read defaults are configurable through `DRNIB_X402_SEARCH_PRICE` and `DRNIB_X402_READ_PRICE`; the returned 402 challenge is the price to approve. These sale endpoints are ordinary service routes, not access to a private project's decrypted evidence.
