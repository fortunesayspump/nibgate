# Nibgate Docs

Nibgate is a verified content discovery and unlock layer for creator-owned paid content. Creators keep content on their own sites, while Nibgate verifies sources, indexes public metadata, and helps humans and agents discover quality work.

<Callout type="info" emoji="✦">
Start with the overview if you want the product model. Jump to quick start if you are ready to integrate the widget and package.
</Callout>
