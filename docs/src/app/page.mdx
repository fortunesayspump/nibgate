# Nibgate Docs

Build paid routes on your own domain with the Nibgate package, hub widget, site verification, content metadata, analytics events, and payment receipts.

<Callout type="info" emoji="✦">
Nibgate is split into two jobs: the **package** gates and unlocks content on the creator site, while the **hub** verifies domains, indexes public metadata, and shows analytics.
</Callout>

## Mental model

Nibgate should be easy for creators and precise for developers. The creator keeps the site, receiver address, and protected content. Nibgate receives enough verified metadata and event data to make the creator dashboard useful.

## Core flow

1. Creator connects wallet and creates a profile.
2. Creator registers the website origin.
3. Dashboard generates a site id and verification token.
4. Creator pastes the widget on the site.
5. Backend verifies ownership and keeps checking health.
6. Creator installs the package and protects routes.
7. Package sends content, unlock, and receipt events.
8. Dashboard and Explore use verified data only.
