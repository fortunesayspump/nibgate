Frequently Asked Questions
A testnet is an instance of a blockchain used specifically for testing. In contrast to a mainnet blockchain, which represents a production environment, testnets allow developers to test their apps and smart contracts without risking assets with real-world value. Testnet tokens are assets that can be freely obtained from testnet faucets to experiment with funds flows on testnets.
Developers can use Circle's Faucet in the Developer Console to obtain testnet ETH and POL. Testnet tokens generated from the Developer Console will be sent to wallet addresses created with Circle Wallets. Get started for free.
This Faucet is public and permissionless for anyone to use. There's no account required, and it can provide free access to testnet USDC and EURC on all supported blockchains.

The Faucet in the Developer Console provides free access to both native tokens on testnet like ETH and POL and stablecoin tokens on testnet like USDC and EURC. It can only fund wallet addresses created with Circle Wallets. Get started for free.
This Faucet provides access to testnet tokens on supported blockchains. See our docs for USDC testnet addresses, EURC testnet addresses, and cirBTC testnet addresses.
