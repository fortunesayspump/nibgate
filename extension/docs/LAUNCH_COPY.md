## Intro thread

**1/7**  
Meet Nibgate: a browser extension for tipping the creators behind what you read. It brings USDC tips to supported articles, tutorials, and papers—without a site rebuild.

Install: https://chromewebstore.google.com/detail/nibgate/hbinjoadmoahedigmjaldiclmakanknf

**2/7**  
On supported content, Nibgate adds a small **Tip the creator** button near the end of the piece. It stays out of your way until you choose to support the author.

**3/7**  
Pick a preset or custom amount. Before anything is signed, review the amount, recipient, payment route, and available fee estimate. You approve—or cancel.

**4/7**  
If the creator can’t be confidently identified, Nibgate won’t send to a guess. The tip is held for the creator to claim; you can refund it if you change your mind.

**5/7**  
Your wallet is self-custodial: keys stay on your device. Site access is optional, and the extension uses no analytics or remote code.

**6/7**  
It starts on Arc Testnet with faucet USDC (play money). Switching to Mainnet requires an explicit confirmation, so real USDC isn’t used by accident.

**7/7**  
Support shouldn’t depend on being on the same platform. Try Nibgate on your next read.

Install from the Chrome Web Store: https://chromewebstore.google.com/detail/nibgate/hbinjoadmoahedigmjaldiclmakanknf

## Screenshot set

Generated by `node extension/scripts/social-shots.mjs` after building the extension with
`cd extension && npm run build`. Output goes to `e2e/screenshots/social/`.
The page captures use public blog URLs; the extension and demo wallet run in a
temporary profile with no real user data. The capture profile pre-grants site
access to avoid a browser permission dialog; the shipped extension still asks
the user before enabling access. No tip is approved or submitted.
